# FlowTrace — Interactive OSI Network Simulator

FlowTrace is a modern interactive OSI 7-Layer network simulator built with React, TypeScript, Zustand, TailwindCSS, Framer Motion, and Recharts.

The project visualizes how data flows through all seven OSI layers while dynamically simulating:

- Packet flow
- Network latency
- Throughput & goodput
- TCP vs UDP behavior
- Frame corruption
- Bit errors
- Routing impact
- Layer interactions
- Simulated packet capture
- Real-time downstream effects

The UI is designed with a futuristic glassmorphism-inspired cyber interface focused on real-time visualization and interactive learning.

# Installation

## 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/flowtrace.git
```

---

## 2. Open Project Folder

```bash
cd flowtrace
```

---

## 3. Install Dependencies

```bash
npm install
```

---

# Required Packages

Main packages used in the project:

```bash
npm install framer-motion recharts zustand
```

Development dependencies:

```bash
npm install -D tailwindcss postcss autoprefixer typescript
```

---

# Run Project

Start development server:

```bash
npm run dev
```

---

# Build Production Version

```bash
npm run build
```

---

# Preview Production Build

```bash
npm run preview
```
